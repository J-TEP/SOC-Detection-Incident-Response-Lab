LESSONS LEARNED
---------------
Detection engineering requires more than syntactically valid rules.
Rule inheritance, event matching, correlation behavior, event indexing,
and the underlying SIEM ruleset must all be validated using actual
telemetry.

Successful detection logic should be verified using repeatable test
activity before being treated as production-ready.
